# MoveIt

A small Android game about copying a choreography with your phone in hand.

You pick a song, a 3-second countdown starts, and then you dance along holding the phone. The accelerometer and gyroscope record your movements, which are compared with a reference choreography recorded beforehand. At the end you get a score from 0 to 100, and each game is saved in a local history.

Developed as a university project for a mobile development course at the University of Pisa. The goal was to work with device sensors and the main building blocks of a modern Android app.
